# ThirdOne IT Services — Corporate website

Official bilingual website for **ThirdOne IT Services**. Source of truth: `gderosa89/thirdone-website`.

## Hosting

Cloudflare **Workers with Static Assets**, deployed via GitHub integration.

- Production domain: https://thirdone.com.ar/
- Worker: `thirdone-website`
- Branch: `main`
- Build command: none
- Deploy command: `npx wrangler deploy`
- Assets directory: `./public` (configured in `wrangler.toml`)

### Deployment verification

After each Git push, confirm the production deployment succeeds in Cloudflare **Workers & Pages → thirdone-website → Deployments**.

Check that the following URLs return HTTP 200 before submitting to search engines:

- https://thirdone.com.ar/
- https://thirdone.com.ar/robots.txt
- https://thirdone.com.ar/sitemap.xml
- https://thirdone.com.ar/es/servicios/cloud-aws-azure/
- https://thirdone.com.ar/en/services/cloud-engineering/

## SEO

- 6 services × 2 languages, available at separate URLs under `/es/servicios/` and `/en/services/`
- HTML canonical, language alternates and Service schema
- Root sitemap and robots.txt
- The homepage remains a client-side language toggle and uses the English version as its canonical. A dedicated Spanish homepage can be added later.

### Google Search Console

1. Add a **Domain property** for `thirdone.com.ar`.
2. Verify ownership with the TXT record generated by Google in Cloudflare **DNS → Records**.
3. Submit `https://thirdone.com.ar/sitemap.xml`.
4. Use URL Inspection to test the homepage and priority service pages.
5. Review indexing and performance reports as data becomes available.

Adding a sitemap does not guarantee indexing or higher rankings.

## Email

Microsoft 365 Exchange Online handles corporate email independently of Workers hosting. Do not delete MX, SPF, DKIM, DMARC or Microsoft domain-verification DNS records during web deployments. The website's contact CTA uses `mailto:contact@thirdone.com.ar`.
